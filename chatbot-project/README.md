# DeepSeek AI Chatbot

A intelligent chatbot powered by DeepSeek AI with knowledge base retrieval capabilities.

## Features

- 🤖 AI-powered responses using DeepSeek AI
- 📚 Knowledge base with FAQ matching
- 💬 Clean chat interface with Streamlit
- 🗣️ Voice input and output (optional)
- 💾 Conversation history storage
- 🔍 Semantic search for FAQs
